# WHY

이 폴더는 로컬 전용 기술 선택 이유 문서 보관용이다.

- 기술, 라이브러리, 패턴, 인프라 도구를 왜 선택했는지 기록한다.
- 대안, 장단점, 적용 대상 코드/기술, 운영 관점을 함께 적는다.
- 파일명은 `<기술명>.md` 또는 `<기능명>-why.md` 형식을 우선 사용한다.
- 이 폴더의 내용은 커밋, 푸시, PR에 포함하지 않는다.
- 해당 폴더에서 기술적인 이유를 시작으로 꼬리물기 질문을 5회정도 자체적으로 진행하고 답변까지 찾아서 명시한다.
- 꼬리물기 질문은 웹서칭을 통해 실제 면접관들이 하는 질문 위주로 진행하고 답변을 제시한다.
